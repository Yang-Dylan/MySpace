# 用户使用指南

## 概述

API自动化测试平台是一个基于Web的测试管理平台，提供完整的API文档管理、测试用例生成、执行和编排能力。

## 快速开始

### 1. 登录系统

1. 访问系统首页
2. 如果还没有账号，点击"注册"创建新账号
3. 使用用户名和密码登录

**默认管理员账号：**
- 用户名：`admin`
- 密码：`123456`

### 2. 上传API文档

1. 进入"API文档管理"页面
2. 点击"上传文档"按钮
3. 选择OpenAPI/Swagger格式的JSON或YAML文件
4. 系统会自动解析文档，提取API接口信息

**支持的格式：**
- OpenAPI 3.0
- Swagger 2.0
- JSON格式
- YAML格式

### 3. 创建测试用例

#### 方法一：手动创建

1. 进入"测试用例"页面
2. 点击"创建测试用例"
3. 输入测试用例名称和描述
4. 从API列表中选择要测试的API
5. 配置API的执行顺序、请求参数等
6. 保存测试用例

#### 方法二：使用可视化编排

1. 进入"可视化编排"页面
2. 点击"创建新流程"
3. 从API列表拖拽API到画布
4. 通过连线连接API，表示执行顺序
5. 配置字段映射关系（可选）
6. 保存编排流程
7. 将编排流程应用到测试用例

### 4. 配置API参数

1. 进入"API配置管理"页面
2. 选择要配置的API
3. 配置以下选项：
   - **重试机制**：失败时自动重试的次数和间隔
   - **等待时间**：API调用前后的延迟时间
   - **依赖关系**：配置API之间的依赖和执行顺序

### 5. 执行测试用例

1. 进入"测试用例"页面
2. 选择要执行的测试用例
3. 点击"执行"按钮
4. 配置执行参数：
   - **线程数**：并发执行的线程数
   - **数据集**：选择测试数据集（可选）
5. 开始执行
6. 查看执行结果和详细报告

### 6. 查看执行结果

1. 进入"测试执行"页面
2. 查看执行历史列表
3. 点击执行记录查看详细信息：
   - 每个API的请求和响应
   - 执行时间
   - 错误信息（如果有）
   - 字段映射结果

## 功能详解

### API文档管理

- **上传文档**：支持上传OpenAPI/Swagger格式的API文档
- **查看文档**：查看已上传的文档详情和解析出的API列表
- **编辑文档**：修改文档信息
- **删除文档**：删除不需要的文档

### 测试用例管理

- **创建用例**：手动创建或通过编排流程创建
- **编辑用例**：修改测试用例配置
- **删除用例**：删除不需要的测试用例
- **权限控制**：只能访问自己创建的或有权限的测试用例

### API配置管理

- **重试机制**：配置API失败时的重试策略
- **等待时间**：配置API调用前后的延迟
- **依赖关系**：配置API之间的依赖和执行顺序

### 测试执行

- **多线程执行**：支持并发执行，提高测试效率
- **数据集驱动**：支持使用多组测试数据执行测试
- **结果记录**：详细记录每次执行的请求和响应
- **错误处理**：自动处理重试、依赖等配置

### 可视化编排

- **拖拽式配置**：通过拖拽方式配置API流程
- **字段映射**：配置API之间的字段关联关系
- **流程保存**：保存编排流程，支持后续编辑
- **应用到测试用例**：将编排流程转换为测试用例

### 数据库管理

- **SQL文件上传**：上传用于数据库初始化和清理的SQL文件
- **SQL验证**：自动验证SQL文件的有效性和安全性
- **执行SQL**：执行SQL文件进行数据库操作
- **操作记录**：查看所有数据库操作的执行历史

## 常见问题

### Q: 如何导入Postman集合？

A: 目前系统支持OpenAPI/Swagger格式。如果使用Postman，可以先将集合导出为OpenAPI格式，然后上传到系统。

### Q: 如何配置API之间的数据传递？

A: 有两种方式：
1. 在测试用例中配置字段映射
2. 在可视化编排中配置字段映射

### Q: 测试执行失败怎么办？

A: 查看执行结果详情，检查：
- API请求是否正确
- 字段映射是否正确
- 依赖关系是否配置正确
- 网络连接是否正常

### Q: 如何提高测试执行效率？

A: 
- 使用多线程执行
- 合理配置重试机制和等待时间
- 使用数据集驱动测试
