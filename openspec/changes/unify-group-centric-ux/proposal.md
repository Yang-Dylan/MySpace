# Proposal: unify-group-centric-ux

## Summary
重构平台 UI/UX，以 API 分组为核心入口，统一所有功能访问路径。登录后直接进入分组列表，移除分散的导航入口，在分组详情页集成接口上传、数据集配置、用例创建和执行等完整功能。

## Motivation
当前系统存在多个分散的入口点（API文档、测试用例、执行记录等独立页面），用户体验碎片化。以分组为中心的设计可以：
- 简化导航，降低学习成本
- 强化分组作为核心组织单元的概念
- 提供更流畅的工作流（从接口管理到用例创建再到执行）

## Changes Requested

### 1. 登录首页调整
- 登录后直接跳转到 API 分组列表页（`/api-groups`）
- 移除原 `Home` 页面

### 2. 分组详情页 - 接口上传功能
- 在分组详情页头部新增「接口上传」按钮
- 点击弹出上传弹窗，包含两个 Tab：
  - **文件上传**：上传 OpenAPI/Swagger 文件
  - **手动添加**：表单方式手动添加单个接口

### 3. 接口详情查看与编辑
- 点击接口列表中的接口行，右抽屉显示接口详情页或直接跳转新页面
- 显示请求参数、返回参数、请求方式、请求头，支持编辑
- 「编辑接口」按钮与点击接口效果一致

### 4. 数据集配置功能
- 在分组详情页头部新增「配置基础数据」按钮
- 弹窗支持：
  - 上传 JSON 格式数据集
  - 手动添加数据集（键值对形式）

### 5. 接口关联用例展示
- 接口列表新增「关联用例」列
- 显示每个接口被多少用例引用
- 点击可展开查看用例名称列表
- 点击用例名称跳转到对应用例页面

### 6. 统一入口，移除分散导航
- 移除顶部导航中的「API文档」「测试用例」独立入口
- 仅保留「API分组」作为主入口
- 所有功能通过分组详情页访问

### 7. 用例可视化页面增强
- 新增「执行用例」按钮，直接在可视化页面执行
- 新增「编辑用例」功能，可在此页面关联字段，拖动接口 更改顺序
- 新增「执行记录」Tab/区域，显示该用例的执行历史
- 点击执行记录跳转到详情页，查看每个接口的执行情况和错误日志

### 8. 用例 Tab 新增用例按钮
- 在分组详情页的「用例」Tab 顶部新增「新增用例」按钮
- 点击打开用例创建页面/弹窗
- API 选择仅限当前分组内的接口

## Scope
- **Frontend**: 路由调整、页面重构、组件新增
- **Backend**: 可能需要新增分组内数据集管理 API、接口关联用例查询 API

## Affected Specs
- `api-doc-management`: 分组内接口上传和手动添加
- `test-case-generation`: 分组内用例创建
- `test-execution`: 可视化页面执行和记录查看
- `visual-orchestration`: 可视化页面增强

## Priority
High - 核心用户体验优化
