# Design: unify-group-centric-ux

## Architecture Decisions

### 1. 路由结构调整

**决策**：登录后默认跳转到 `/api-groups`，移除 `/` 路由或将其重定向。

```
/ -> redirect to /api-groups
/api-groups -> API分组列表（首页）
/api-groups/:id -> 分组详情页（集成所有功能）
/api-groups/:id/apis/:apiId -> 接口详情页
/api-groups/:id/test-cases/create -> 创建用例（限本分组API）
/test-cases/:id/visual -> 用例可视化（增强版，可执行和编辑）
/test-executions/:id -> 执行详情页
```

**移除的独立路由**：
- `/api-docs` 系列（由分组详情页替代）
- `/test-cases` 列表页（由分组详情页替代）

### 2. 分组详情页模块化设计

**决策**：分组详情页采用头部操作区 + Tab 内容区的布局。

```
┌──────────────────────────────────────────────────────────┐
│  ← 返回    [分组名称]                                      │
│            描述文本                                        │
│                                                          │
│  [接口上传]  [配置基础数据]                    接口: 12  用例: 5 │
├──────────────────────────────────────────────────────────┤
│  [接口 (12)]  [用例 (5)]  [数据集 (3)]                     │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  Tab 内容区域                                             │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 3. 接口上传弹窗设计

**决策**：使用模态弹窗而非跳转页面，保持上下文。

- **文件上传 Tab**：复用现有 `ApiDocUpload` 逻辑
- **手动添加 Tab**：表单包含 method、path、summary、请求参数、响应参数

### 4. 接口详情展示方式

**决策**：采用侧边抽屉（Drawer）而非新页面，便于快速浏览和编辑。

- 点击接口行 → 打开右侧抽屉
- 抽屉内容：基本信息、请求参数列表、响应参数列表
- 参数可编辑（inline 或表格形式）
- 保存后更新 `is_available` 状态

### 5. 数据集管理

**决策**：分组级数据集，与分组绑定。

**后端模型扩展**：
```python
class GroupDataSet(Base):
    id = Column(Integer, primary_key=True)
    group_id = Column(Integer, index=True)
    name = Column(String(100))
    data = Column(JSON)  # 数据内容
    created_at = Column(DateTime)
```

**前端交互**：
- 上传 JSON 文件解析为数据集
- 手动添加支持键值对编辑器

### 6. 接口关联用例查询

**决策**：新增后端 API 支持查询接口关联的用例。

```
GET /api/apis/{api_id}/test-cases
返回: { items: TestCase[], total: number }
```

### 7. 可视化页面增强

**决策**：在现有可视化页面基础上增加操作区。

```
┌──────────────────────────────────────────────────────────┐
│  ← 返回    [用例名称]                                      │
│            描述                                           │
│                                                          │
│  [执行用例]  [编辑用例]                      执行记录 (5)    │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  可视化流程图区域                                          │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  最近执行记录                                              │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 2024-12-29 10:30  成功  耗时 2.3s          [详情]   │  │
│  │ 2024-12-29 09:15  失败  耗时 1.8s          [详情]   │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

### 8. 导航简化

**决策**：仅保留必要的顶部导航。

- API分组（主入口）
- 用户信息和退出

移除：API文档、测试用例等独立入口

## Risks & Mitigations

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 用户习惯改变 | 老用户可能不适应 | 保留旧路由重定向，添加引导提示 |
| 分组详情页过于复杂 | 加载慢、难以维护 | 组件拆分、懒加载、分步渲染 |
| 后端 API 扩展 | 开发工作量增加 | 优先使用现有 API，仅必要时新增 |

## Dependencies

- 现有 API 分组功能（已完成）
- 现有用例可视化功能（已完成）
- 测试执行服务（已完成）
