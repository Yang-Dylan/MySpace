# 修复用例执行405错误和页面返回tab定位

## 概述

修复两个问题：
1. 用例执行时报错405（Method Not Allowed）
2. 页面返回到上一级时能够定位到对应的tab，用例详情页返回时定位到用例tab下

## 需求

1. **修复用例执行405错误**
   - 检查后端API路由配置
   - 确保前端调用正确的HTTP方法
   - 验证API路径是否正确

2. **实现页面返回时tab定位**
   - 用例可视化页面返回时，能够定位到对应的tab
   - 从用例详情页返回时，定位到用例tab下
   - 使用React Router的location.state传递tab信息

## 验收标准

- [x] 用例执行不再报错405
- [x] 从用例详情页返回时，自动定位到用例tab
- [x] 页面返回时能够正确显示对应的tab内容
