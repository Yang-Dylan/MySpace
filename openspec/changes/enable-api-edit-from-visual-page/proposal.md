# 用例可视化页面点击接口打开API编辑

## 概述

在用例可视化页面，用户点击接口卡片时，应该能够打开API详情抽屉，查看和编辑API的详细信息，包括标签、请求参数和响应参数。

## 需求

1. **点击接口卡片打开API编辑**
   - 在用例可视化页面的接口卡片上添加点击事件
   - 点击后打开API详情抽屉
   - 抽屉中显示API的详细信息，包括：
     - 基本信息（方法、路径、摘要）
     - 标签（可添加、删除）
     - 请求参数（可添加、修改、删除）
     - 响应参数（可添加、修改、删除）

2. **API编辑功能**
   - 支持编辑标签
   - 支持添加、修改、删除请求参数
   - 支持添加、修改、删除响应参数
   - 保存后自动刷新可视化数据

3. **用户体验**
   - 接口卡片添加悬停效果，提示可点击
   - 添加"编辑"按钮，提供明确的编辑入口
   - 抽屉从右侧滑出，不影响当前页面查看

## 验收标准

- [x] 点击接口卡片可以打开API详情抽屉
- [x] 点击"编辑"按钮可以打开API详情抽屉
- [x] API详情抽屉显示完整的API信息
- [x] 可以编辑标签、请求参数、响应参数
- [x] 保存后自动刷新可视化数据
- [x] 所有操作都有适当的错误处理
