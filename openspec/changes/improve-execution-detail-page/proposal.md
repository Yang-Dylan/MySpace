# 调整执行详情页面的返回和展示详细报错

## 概述

优化测试执行详情页面，包括：
1. 调整返回功能，支持返回到用例详情页
2. 展示详细的报错信息，包括执行错误和每个API的错误详情

## 需求

1. **调整返回功能**
   - 从用例详情页跳转到执行详情页时，返回按钮应该返回到用例详情页
   - 使用React Router的location.state传递返回路径信息

2. **展示详细报错**
   - 在执行详情页面顶部显示执行级别的错误信息（如果有）
   - 在每个执行结果中，如果失败，显示"查看详情"按钮
   - 点击"查看详情"后，展开显示该API的详细错误信息、请求URL、状态码等

## 验收标准

- [x] 从用例详情页跳转到执行详情页后，返回按钮能正确返回到用例详情页
- [x] 执行级别的错误信息能够正确显示
- [x] 每个失败的API结果都能展开查看详细错误信息
- [x] 错误信息以清晰的格式展示，包括错误消息、请求URL、状态码等
