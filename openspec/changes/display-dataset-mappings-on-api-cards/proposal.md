# 在接口卡片上显示数据集的映射关系

## 概述

在用例可视化页面的接口卡片上，需要显示该接口的字段映射关系，包括来自数据集的映射和来自其他API的映射。

## 需求

1. **后端支持数据集映射**
   - 修改`VisualFieldMapping`模型，添加`source_type`和`source_data_set_id`字段
   - 在处理`enhanced_field_mappings`时，将数据集映射（`source_type == "data_set"`）也添加到`incoming_mappings`中

2. **前端显示映射关系**
   - 在接口卡片上添加"字段映射"区域
   - 显示所有映射关系，区分数据集映射和API映射
   - 显示源字段和目标字段的对应关系

3. **用户体验**
   - 映射关系以清晰的卡片形式展示
   - 数据集映射显示"📦 数据集"标识
   - API映射显示"API #序号"标识

## 验收标准

- [x] 后端支持数据集映射类型
- [x] 接口卡片上显示字段映射关系
- [x] 区分数据集映射和API映射
- [x] 显示源字段和目标字段的对应关系
