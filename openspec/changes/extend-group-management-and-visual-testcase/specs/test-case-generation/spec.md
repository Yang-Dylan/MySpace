# test-case-generation Spec Delta

## ADDED Requirements

### Requirement: 条件执行配置
系统 SHALL 支持用户为测试用例中的API配置条件执行规则。

#### Scenario: 配置单条件执行
- **WHEN** 用户编辑测试用例中某个API的条件配置
- **AND** 选择前置API的响应字段
- **AND** 选择运算符（等于、不等于、包含等）
- **AND** 输入期望值
- **THEN** 系统保存条件配置
- **AND** 执行时根据条件决定是否执行该API

#### Scenario: 配置多条件组合
- **WHEN** 用户为API配置多个条件
- **AND** 选择条件逻辑（AND或OR）
- **THEN** 系统保存多条件配置
- **AND** 执行时根据组合逻辑判断条件是否满足

#### Scenario: 配置条件不满足的处理策略
- **WHEN** 用户配置条件执行
- **AND** 选择失败处理策略（跳过/失败/继续）
- **THEN** 系统保存处理策略
- **AND** 条件不满足时按策略处理

#### Scenario: 条件执行结果记录
- **WHEN** 测试执行时某API的条件不满足
- **THEN** 系统记录条件判断结果
- **AND** 在执行报告中显示跳过原因或失败原因

### Requirement: 用例可视化展示
系统 SHALL 支持用户以可视化方式查看测试用例的API调用链。

#### Scenario: 查看用例可视化视图
- **WHEN** 用户在用例列表或详情页点击可视化按钮
- **THEN** 系统展示用例的可视化视图
- **AND** 以卡片流形式显示API调用顺序
- **AND** 每个卡片显示API方法、路径、关键参数

#### Scenario: 查看参数传递关系
- **WHEN** 用户查看可视化视图
- **THEN** 系统以连线形式展示API之间的字段映射
- **AND** 每个API最多显示3个关键参数
- **AND** 支持展开查看全部参数

#### Scenario: 查看条件配置
- **WHEN** 用户查看配置了条件执行的API卡片
- **THEN** 系统显示条件标识
- **AND** 支持悬停或点击查看条件详情
